# 方案 A 蒸馏：内容星系

## 核心原则

首页承担“知道这里是什么、选择一个入口、开始一个任务”。星系是可交互导航和探索体验；正文保持独立 HTML，不烘焙进画布。学习页按四阶段组织十二部分；关于页说明公开方法、作品与收益承诺边界。

## 视觉

全站采用深海军蓝背景、冷白正文、青色行动色和少量紫色层次。字体使用系统中文无衬线。主标题与重要动作拥有清晰对比，光晕与粒子不能覆盖正文。颜色由共享 CSS 自定义属性管理。

场景按远处星场与星系、中景不规则旋臂、炽热内核、近景尘埃组织。不同深度的运动与镜头位移产生视差；前景掠镜只在接近时增强，淡出避免突兀穿模。内核保持最强视觉焦点，射流与远景亮度受控。不追求天文学精确性。

## 交互契约

- 默认缓慢旋转；支持暂停、拖动、靠近和恢复视角。
- 点击地标或下方入口显示说明与明确链接，不直接跳页。Escape 关闭详情并恢复焦点。
- 镜头通过阻尼过渡；减少动态效果偏好下禁用自动旋转并直接定位。
- 手机端隐藏画布浮动标签，下方保留双列入口。横向手势超过 10px 后才接管；纵向页面滚动与双指缩放保留。
- 手机按钮至少 44px；阅读区位于画布之外。
- 页签隐藏、场景离屏时暂停渲染。设备像素比上限 1.5；WebGL 初始化失败或上下文丢失时展示降级提示，内容入口继续可用。

## 迭代检查

每轮检查三页导航、节点选择、关闭详情、暂停、靠近/恢复、窄屏溢出和上下滑动。对性能的设备结论需要真机测量，桌面移动视口不能代替真机帧率。保持减少动态效果、可见焦点和强制颜色模式。

本次范围是选定方案的代码归整与接入既有构建。原游戏列表保留在 games.html；未重新设计游戏 UI，未扩展账号、支付、采集或内容发布功能。
